## 购买前的实用检查

下单前可按以下顺序核对，避免只被套餐名或首页起步价带着走：

1. **确认应用最低资源需求。** 估算常驻进程、数据库和缓存的内存占用，给运行余量，不要把全部内存都预先算给应用。

3. **选择机房。** 访客主要在哪个地区，通常比套餐名称更影响访问延迟。具体可选地点和库存以订单页面为准。
4. **看完整账期。** 特别注意 40G 的半年计费，以及其他套餐在结账页显示的实际付款总额。
5. **评估自管理能力。** 你需要能够处理系统更新、账户安全、软件安装和故障排查，或另行安排管理服务。
6. **确认退款与服务条款。** 官网首页列有 30 天退款政策和 99.9% uptime guarantee；购买前应查看适用于具体服务的条款与条件。
